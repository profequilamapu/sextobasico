¿Qué es un ángulo?

Es la abertura entre dos semirrectas que parten del mismo punto, llamado vértice. Lo medimos en grados (°).

Antes de empezar: una vuelta completa tiene 360°, un ángulo llano tiene 180° y un ángulo recto tiene 90°.

1. Ángulos opuestos por el vértice

Cuando dos rectas se cruzan, los ángulos que quedan frente a frente son iguales. Los que están uno al lado del otro sobre una recta suman 180°.

Frente a frente = IGUALES
🧠 Truco: imagina una X. Los ángulos que se miran de frente son gemelos.

Ejemplo con álgebra

Si los opuestos son 2x + 15° y 5x − 30°:

2x + 15 = 5x − 30
45 = 3x
x = 15
Ángulos: 2 · 15 + 15 = 45° cada uno.
Los adyacentes: 180 − 45 = 135°.

2. Complementarios

Son dos ángulos que suman 90°.

A + B = 90°

Si A = 35°, entonces B = 90 − 35 = 55°.

🧠 COmplementarios = COnstruyen una esquina de 90°.

3. Suplementarios

Son dos ángulos que suman 180°.

A + B = 180°

Si A = 120°, entonces B = 180 − 120 = 60°.

🧠 SUplementarios = forman una línea recta, como el SUelo.

¿Y si aparece una x?

Complementarios: A = 3x + 10°, B = x + 20°

(3x + 10) + (x + 20) = 90 → 4x + 30 = 90 → x = 15.
A = 55° y B = 35°.

Suplementarios: A = 4x°, B = x + 30°

4x + x + 30 = 180 → 5x = 150 → x = 30.
A = 120° y B = 60°.

4. Rectas paralelas y una transversal

Las paralelas nunca se cruzan. Cuando otra recta las corta, aparecen ángulos relacionados.

Correspondientes

Misma posición en cada cruce. Ejemplo: 1 y 5. Son iguales.

Alternos internos

Entre las paralelas y a lados opuestos de la transversal. Ejemplo: 3 y 6. Son iguales.

Alternos externos

Fuera de las paralelas y a lados opuestos. Ejemplo: 1 y 8. Son iguales.

Ejemplo algebraico: dos ángulos alternos internos miden 2x + 25° y 4x − 15°. Como son iguales: 2x + 25 = 4x − 15 → 40 = 2x → x = 20; ambos miden 65°.

🧠 Recuerda: correspondientes = misma esquina; alternos = lados contrarios; internos = dentro; externos = fuera.

5. Ángulos interiores de triángulos

¡No importa si el triángulo es alto, bajo, ancho o delgado! Sus tres ángulos interiores siempre suman 180°.

A + B + C = 180°

Ejemplo: si dos ángulos miden 50° y 70°, el tercero es 180 − 50 − 70 = 60°.

Ejemplo con x, paso a paso

Ángulos: 2x + 20°, 5x − 10° y x + 10°.

(2x + 20) + (5x − 10) + (x + 10) = 180
8x + 20 = 180
8x = 160
x = 20
Ángulos: 60°, 90° y 30°.
Comprobación: 60 + 90 + 30 = 180° ✓
🧠 Truco: «triángulo = tres ángulos, una suma: 180°».
